JianYing-Period-Keeper integration: https://github.com/Kirota233/JianYing-Period-Keeper
Upstream version: 1.0.5; commit c6552bcfe86573be72e442aa9af292ad1047972b.
The punctuation tables and clipboard text mappings are adapted into a native Windows helper and the workspace panel. Upstream provides no LICENSE file at this commit; its README describes personal audiovisual creation, learning and communication use. The downloaded upstream source is preserved in the development workspace.
The integrated component modifies only matching in-memory punctuation tables, records its own changes for restoration, and supports explicit protected-text copying. Upstream availability status is respected; remote code updates and self-deletion are not implemented in this integrated application.
