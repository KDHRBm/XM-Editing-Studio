# XM剪辑台独立卸载工具

运行 `scripts/build-uninstaller.ps1` 构建独立 EXE，产物默认在 `artifacts/XM-Editing-Studio-Uninstaller.exe`。
启动后扫描原版安装目录，也可以手动选择。只有原版安装标记、主程序和 C# 版程序清单同时存在时才允许卸载。

卸载只删除清单内的程序文件，以及经确认的安装标记和安装器自己的卸载程序。默认保留 `data`、备份、用户放入安装目录的额外文件；不会递归删除目录，也不处理 fork。安装程序在运行或文件被占用时会停止。

若旧版 `data` 目录阻止重新安装，可以勾选将旧 `data` 移到安装目录同级的独立备份文件夹。该选项只移动目录，不删除内容，完成后显示备份路径。
