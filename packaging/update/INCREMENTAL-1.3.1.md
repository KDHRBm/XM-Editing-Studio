# 1.3.0 / 1.3.1 → 1.3.1 累计增量包

本地制作日期：2026-10-27。本包包含 1.3.0 发布后的全部 1.3.1 功能、本地选择性移植的 DeepSeek 读取与分段容错改进，以及称谓句点和台词横线保留修复。目标版本继续显示 1.3.1，修订标识为 `20261027-title-dash`。本包未上传 GitHub。

## 适用版本

- 原始 1.3.0 完整安装版及对应全量更新版。
- 后续 1.3.0 DeepSeek 回答接回修订版、独立模型选择修订版、中文字幕修订版。
- 已发布的 1.3.1 完整安装版。
- 已安装 2026-10-26 的 1.3.0→1.3.1 累计增量包（含 DeepSeek 改进）的版本。
- 本机已经应用本次改进的 1.3.1 会提示无需重复更新。

更新器依据完整文件哈希自动选择差异。相同版本号但文件被修改、混装或来自其他 fork 的构建，不会强制覆盖。本包不能独立安装，不适用于 1.1.x / 1.2.x。

## 本次新增修复

- 保留英文和西语称谓后的句点，例如 `Mr. Harris`、`Ms. Foster`、`Dr. Green`、`Sra. López`，断句不会把称谓与名字拆开。
- 兼容复制到剪映时沿用相似字符保护：`Mr.` 转为 `Mr․`；界面和 TXT 保留标准英文句点。
- 保留台词首尾及单词内部的 `-`；原文 `You—` 整理为 `You -`，不再删除中断横线。
- 工作空间、跑量剪辑流、TXT 导出和复制到剪映同步使用修复后的规则。

## 使用方法

1. 保存当前任务，完全退出剪辑台。
2. 将 ZIP 完整解压到软件目录以外的文件夹，不要只提取 EXE，也不要在 ZIP 内直接运行。
3. 运行 `XM-Update-1.3.1-Incremental.exe`。
4. 选择原软件目录，例如 `D:\小马剪辑台`。目录内应有 `小马剪辑台.exe` 和 `resources`。
5. 等待校验、备份和更新完成，再使用原快捷方式启动。

程序盘建议预留至少 2 GB。更新器仅重建需要变更的主程序、应用归档和标点组件，复用已有且经过校验的运行环境；配置、账号登录资料、任务历史、音乐、素材、自定义路径和卸载程序不属于更新文件。

## 恢复

更新前的原文件保存在软件目录 `.xiaoma-update-backups` 内，备份名称含 `delta131`。运行 `Restore-Previous.cmd`，选择本次更新产生的备份文件夹，即可恢复到更新前的版本。恢复前同样需要完全退出软件。

更新器校验差异数据、共享数据块、重建文件及备份，遇到事务失败会尝试自动恢复已替换的文件。电源中断等情况可重新运行恢复工具；保留备份，不要手动混搭 EXE 和 app.asar。

## 开发构建

`scripts/build-incremental.mjs` 接收经过核对的本地基线清单与一个全新输出目录，生成 `manifest.json`、`patches/` 与 `blocks/`。相同目标数据按内容共享，未变化的运行文件不进入包。脚本不会清空已有输出目录。

编译 `IncrementalUpdater.cs` 时同时编译生成的 `IncrementalManifestHash.cs`，目标为 Windows x64 WinExe，引用 `System.Web.Extensions.dll`、`System.Windows.Forms.dll`、`System.Drawing.dll`。正式包禁止定义 `UPDATE_TEST`；该标志仅在隔离检查中开启故障注入。

压缩包白名单仅包含正式更新器、清单、差异、共享块、说明和恢复入口，不包含测试程序、构建目录、日志或用户数据。校验记录与 ZIP SHA-256 随交付保存在本地。
