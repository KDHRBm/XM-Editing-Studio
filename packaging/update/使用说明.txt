XM剪辑台 1.3.0 全量更新包
适用 Windows 10 / Windows 11 64 位（x64）

使用方法
1. 把整个 ZIP 解压到原软件目录之外，例如桌面。
2. 保存任务，完全退出 XM剪辑台 / 小马剪辑台。
3. 运行 XM-Update-1.3.0-Full.exe，选择原程序目录，例如 D:\小马剪辑台。
4. 原目录应包含 小马剪辑台.exe、XM剪辑台.exe 或 黑曜信号台.exe，以及 resources 文件夹。
5. 更新器会验证安装目录、校验全部更新文件，先备份再替换，完成后使用原快捷方式打开。

这是完整运行文件更新包，不需要先更新至 1.1.2、1.1.3 或 1.2.0，不要求旧版具有特定文件哈希。适用于本软件可识别的旧版本；新电脑首次安装请使用完整安装包。
建议原程序所在磁盘至少预留 2 GB 空间。若安装目录需要管理员权限，请以管理员身份运行更新器。

保留与回退
保留 API 配置、剧本历史、作品、自定义目录、用户音乐及原卸载入口。只替换程序清单中的文件。
更新前的原文件保存在程序目录的 .xiaoma-update-backups 下。替换失败时自动回滚。
需要回退时运行 Restore-Previous.cmd，选择本次带 full130 的备份目录。
更新期间不要打开软件，不要删除更新文件与备份。
