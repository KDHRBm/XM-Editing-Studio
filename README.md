# XM剪辑台

**1.4.4 累计增量更新已发布**，包含 1.4.3 全部修改和四步 F8 坐标录制，支持原版 **1.4.2、1.4.3** 直接更新。首次安装及 1.3.1 等旧版本，请先使用 1.4.2 完整安装包，再应用 1.4.4 增量包。软件使用 C# + WebView2 主程序，配置、任务和历史保存在安装目录的 `data`。详见 [1.4.4 更新说明](CHANGELOG-1.4.4.md) 和 [迁移说明](docs/CSHARP-MIGRATION.md)。

**把剧本、字幕、音乐和剪映常用工具放进一个工作台。**

XM剪辑台面向短剧剪辑与批量制作：粘贴剧本，整理中文／英文／西语台词，按整篇或不同情节分析配乐，在本地音乐库里找合适的音乐，或交给 Suno 生成，再继续完成样片水印和剪映工程处理。

[下载安装](https://kdhrbm.github.io/XM-Editing-Studio-Website/) · [更新说明](CHANGELOG-1.4.4.md) · [查看源码](app) · [参与开发](CONTRIBUTING.md) · [反馈问题](https://github.com/KDHRBm/XM-Editing-Studio/issues)

## 剪辑台能做什么

### 跑量剪辑流（第一项）

- 粘贴多集剧本后自动识别集数，默认 DeepSeek 联合批量分析，也可选择已配置的 Gemini。
- 每集独立保存任务卡，点击弹出字幕、本地音乐推荐和原剧本，支持单张关闭与一键清空。
- 与工作空间分析独立，只匹配本地音乐；最顶端的字幕标点保留默认开启。
- 支持中断、继续、失败重试和任务备份。超长输入按多集分组处理，详见 [跑量剪辑流使用说明](docs/BATCH-ANALYSIS.md)。

### 剧本与字幕整理

- 识别 `[EN]` 英文、`[ES]` 西语，以及中文角色台词，按对应模式提取所需语言。
- 去掉角色名前缀、场景与动作说明，保留角色冒号后的台词，长句按停顿和意群分行。
- 中文字幕模式不保留标点，便于剪映文稿匹配；完整剧本仍保留原文供 AI 分析，英文和西语继续保留标点。
- 保留重音字母和西语标点；普通句号使用标准英文 `.`，省略号统一为 `...`。
- 复制台词、导出 TXT／台词清单，支持剪映文稿匹配的兼容标点保护。保护模式下逗号、句点和省略号使用近似保护字符；整理区与 TXT 仍显示标准英文标点。
- 多个剧本切换，最多保存 5 份历史剧本，可查看各自的历史推荐；台词区可收起，支持清空当前内容和历史。

### AI 分析剧本与配乐

- 使用 Gemini 或已配置的兼容连接分析完整剧本，提取情绪、情节与音乐关键词。
- 接入 DeepSeek、豆包官方网页版，使用自己的账号登录，无需为这两个入口配置 API 密钥。
- 支持整篇分析，也可按不同情节分段，为每段提供独立推荐或生成提示词。
- 本地匹配与 Suno 生成分区操作，两个分析模型独立选择、分别保存，切换互不影响。模型菜单显示完整名称，进度和按钮使用简短名称。
- 支持中断、超时提示和异常处理；网页自动读取失败时可粘贴完整分析结果继续。网页服务仍受官方登录、验证码、限流和额度规则约束。

### 本地音乐库

- 连接本机或可访问的磁盘目录，扫描音乐标题与关键词，支持多个文件夹和子目录。
- 自定义检索关键词，按相关度或随机顺序选择音乐。每个情节以 5–8 首有效推荐为目标，不足时复核并说明原因。
- 整篇推荐与分段推荐均支持试听、使用和“标记已使用”；再次点击可取消。独立历史栏跨剧本保存最近 10 首使用音乐，工作空间和跑量剪辑流均可查看。
- 下一次检索和推荐候选避开最近使用音乐，试听不自动计入历史。
- 本地音乐库与分析配乐独立折叠。音乐列表分页显示，可将可访问的本地音乐拖入剪映；在线音乐需先成为本地文件才能进行文件拖动。

### Suno 音乐生成

- 自定义音乐风格、情绪、乐器与结构，支持纯音乐和歌词创作，风格输入上限 1000 字符。
- 从整份剧本生成配乐，或按多个情节分别生成多段音乐。
- 工作空间中的配乐任务按每次提交归入独立批次卡，可分别展开、收起，查看同批各段的进度。
- 分段没有合适本地推荐时，可快捷为当前段创建音乐生成任务。
- 查看任务状态和作品，试听、下载与拖入；“我的作品”每页显示 10 首，可独立收起。
- 按音乐调性和乐器命名保存文件，Suno 保存目录与本地素材目录分别设置。

**Suno 生成需要有效 API；需要 Suno API 可联系小马获取。** 生成结果和计费以所选服务商为准。

### 样片水印

- 内嵌水印处理页面，支持批量视频、自定义水印和输出参数。
- 支持本地 FFmpeg WASM 处理，以及 Chrome／Edge WebAV 处理窗口，并可带入软件内已选视频。
- 提供进度、中断、已处理任务、清理与折叠操作。
- 文件或文件夹可拖到桌宠上，递归读取素材后选择改名或加水印；改名先预览，水印成片另存到原目录。
- 视频处理在本地完成。硬件加速是否可用取决于浏览器、显卡、驱动和视频编码。

### JianYing-Ai-Pro

功能分为批量导出、字幕工程、批量改名与样片水印。字幕工程会记住草稿根目录和 SRT 导出目录，模型连接复用现有配置。

主要操作：

| 功能区 | 主要操作 |
| --- | --- |
| 批量导出 | 录制坐标、AI 识别当前屏幕可见草稿、从所选草稿开始导出、切换导出模式和等待时间 |
| 字幕工程 | 提取字幕并隐藏轨道、统一字体、恢复字幕显示，修改前备份 |
| 批量改名 | 按集数模板或 AI 命名，先预览再执行，检查重名与扩展名 |
| 模型连接 | 复用工作空间已配置的 Gemini 连接，无需重复填写密钥 |

批量导出需先在自己的屏幕上录制坐标；`F8` 录制、`F9` 跳过相应步骤、`F10` 中断。字幕工程修改前应退出剪映。

### 统一工作空间

- 在“模型与连接 → 界面与主题”选择 11 款全局主题，包括 iOS 柔和、曜石、暗红、暗蓝、暗紫、墨绿等，导航与各功能页同步切换。
- 工作区按字幕与生成、本地曲库、任务队列三张分项卡切换；左侧导航提供悬停反馈。
- 可拖动分隔栏，右侧快捷栏可整栏隐藏，功能区独立折叠。
- 剪映快捷启动，自动检测并支持手动定位；最多 8 个自定义文件夹快捷入口。
- 播放另一首时暂停上一首，支持空格控制试听，并保留输入区域正常打字行为。
- 大肥鱼桌宠使用「溟月」原版透明动画，支持点击、拖拽、漫游和任务状态动作。角色素材仅限个人非商业使用，参见第三方声明。原版与 fork 可分别启动，数据和端口独立。

## 一次典型工作流程

1. 在工作空间粘贴剧本，选择台词语言并整理。
2. 选择分析模型与整篇／分段模式，分析剧情和音乐关键词。
3. 检索本地音乐或查看 AI 推荐，试听后使用并记录历史；需要新音乐时创建 Suno 任务。
4. 复制台词，把本地音乐拖入剪映，继续编辑。
5. 根据需要批量导出、处理字幕工程、改名和添加样片水印。
