# XM剪辑台

面向短剧制作的 Windows 工作台：剧本与字幕整理、AI 剧本配乐分析、本地音乐检索、Suno 音乐生成、样片水印及 JianYing-Ai-Pro 工具。

此仓库用于发布完整程序包、更新包和使用说明，不包含项目开发源码。

## 1.3.0 主要更新

- 右侧集中 Suno 生成操作；本地匹配设置整合进“分析配乐”，与音乐库独立折叠。
- 模型选择菜单显示完整名称，其余位置使用 Gemini、DeepSeek、豆包等简称。
- DeepSeek、豆包官方网页版接入剧本分析，使用自己的账号登录，无需为这两项配置 API。
- 音乐随机检索、标记已使用、最近 10 首使用历史，后续检索与推荐避开最近使用项。
- 修复重音拉丁字符截断；省略号统一整理为三个标准英文句点 `...`，导出和复制同步保留。

完整变化见 **[1.2 → 1.3 更新说明](CHANGELOG-1.3.0.md)**。

## 如何安装与更新

首次安装：运行完整安装包，选择专用安装目录。

已有旧版：完整解压更新 ZIP 至原软件目录之外，保存任务并退出软件，运行 `XM-Update-1.3.0-Full.exe` 并选择原软件目录。更新器校验文件、备份后再替换，保留个人配置、历史与额外素材。原快捷方式可继续使用；程序文件保留 `小马剪辑台.exe` 名称。

需要回退时运行更新包中的 `Restore-Previous.cmd`，选择原目录 `.xiaoma-update-backups` 中本次带 `full130` 的备份。

## 开始使用

1. 在工作空间设置所需模型连接。使用 Suno 生成音乐需要有效 Suno API；可联系小马获取。
2. 使用 DeepSeek、豆包时，在软件中的官方网页登录自己的账号。官网验证码、限流和额度规则仍然适用。
3. 连接本地音乐库，选择本地素材目录与 Suno 保存目录。
4. 粘贴剧本，整理台词，选择整篇或分段分析，再匹配本地音乐或创建 Suno 音乐任务。

更换电脑后需要重新登录并选择本机目录；公共程序包不包含个人配置、账号、剧本或音乐。
