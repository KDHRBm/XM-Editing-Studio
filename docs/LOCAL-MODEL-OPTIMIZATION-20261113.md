# XM剪辑台 1.6.2 本地更新 — 本地配乐分析优化

- 本地模型根据当前连接的音乐库生成情绪、场景与乐器词表；无需手工修改提示词，换电脑重新下载模型后同样生效。
- 检索优先考虑主导情绪，区分实际战斗与一般紧张，再考虑场景和乐器；保留用户检索偏好及同名编号曲目的候选多样性。
- 整集、分段、单剧本和批量分析共用本地模型流程。
- 选曲时提供本段原文，模型返回证据行号，程序校验范围后引用真实原文与完整曲名。候选语义去除独立乐器标签，减少未经试听的音色推测。
- 合格理由直接保留，仅修正不合格项；修正也采用 JSON Schema。中文与外语原文均可作为依据。
- 本地结构化输出使用低随机性参数，继续保留候选 ID 校验、相邻集去重、有限重试和取消机制。

提示：依据文件名进行语义筛选，音频节奏、响度及对白遮挡仍需试听确认。模型可能误解剧情，软件无法保证每次推荐都正确。
