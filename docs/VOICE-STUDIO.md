# 音频克隆（VoxCPM2）

左侧独立“音频克隆”选项卡。首次进入仅查询本地文件状态，不下载、不启动 Python，不占用模型显存。
点击“下载安装模型”后，在安装数据目录 `data/voxcpm` 部署隔离 Python、PyTorch 和 VoxCPM 2.0.3。
安装包只携带页面、原生桥接和四个小型运行脚本/清单文件，不携带权重或 Python。

## 功能

- 声音设计：输入声音描述与目标文本。
- 音频克隆：参考音频保留音色，可附加情绪、语速描述。
- 极致克隆：参考音频和准确原文共同输入，不附加控制描述。
- 可选本地 SenseVoice 原文识别与 ZipEnhancer 降噪，使用时才下载辅助模型。
- 生成步数、引导强度、随机种子、数字规范化、CPU/CUDA 设备选择。
- 模型下载进度、当前文件速度与剩余时间、停止与重试续传。
- 合成阶段显示真实已生成音频时长，不虚构完成百分比。
- 自动保存 WAV、试听、另存为、最近 30 条记录。

## 运行边界

主模型约 4.96GB，建议预留 18GB 安装空间。CUDA 模式生成前检查空闲显存；不足 5.7GB 时明确提示释放其他模型，用户也可选择 CPU。参考音频 0.5–30 秒、100MB 以内；目标文本最多 1500 字。长剧本分段生成。

推理通过本机子进程执行，不开放 HTTP 监听端口；取消只终止本次由剪辑台启动的进程树。每次任务结束即退出进程并释放模型。下载到 `.part` 文件并校验 SHA256 后才原子替换；失败不标记部署完成。临时请求文件在完成/失败后清理，历史音频与现有 Ollama 模型不删除。

## 验证

`node --test tests/test-voice-studio.mjs` 验证首次进入无下载、点击才部署、模式校验与轻量打包边界。
`python tests/test-voice-worker.py` 验证参数、路径边界、Range 续传、服务器不支持续传时重新下载、错误哈希拒绝安装。
不下载真实权重的测试不代表已验证最终语音质量；实际质量与耗时需用户部署模型后验证。
