# 生成字幕后还原标准标点

兼容复制把英文句点和逗号替换为外观相近的 Unicode 字符。不同字体与剪映排版规则可能将替代句点单独换行。新增的「JianYing-Ai-Pro → 字幕工程 → 检查并还原标准标点」将生成后的字幕还原为正常字符。

1. 在剪映完成文稿匹配，保存草稿并完全退出剪映。
2. 选择草稿根目录，或直接选择一个草稿文件夹。
3. 点击「检查并还原标准标点」，查看待处理草稿并确认。
4. 处理完成后重新打开草稿，检查排版。

替换范围为已用于字幕轨道的素材，`․` / `﹒` 转为 `.`，`‚` / `﹐` 转为 `,`。三个替代句点 `․․․` 变成三个标准句点 `...`。原有中文标点、台词内容和显式换行不变；显示文本、识别文本及逐词字幕文本同步还原。转换前后字符长度相同，保留字体样式范围、时间轴、逐词时间、位置和轨道显示状态。普通标题和未使用素材不处理。

支持普通 JSON 和已有兼容接口可读取的 11.6.5 / 11.7.5 加密草稿，同步处理主文件和 Timelines 内的字幕副本。写入前检查文件是否变化并备份，写入后重新读取校验，失败回滚；备份位于原文件旁，名称包含 `.before_standard_punctuation_`。

此功能按用户点击执行，不监控或修改正在编辑的草稿。还原后可消除替代字符造成的差异，但不调整字幕框宽度、字体或用户主动插入的换行，也不合并已被剪映拆成独立时间片的纯标点字幕。实际画面仍需在剪映重新打开后确认。
