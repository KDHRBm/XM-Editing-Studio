# 本地水印功能移植

> 历史开发记录：文中的本地路径、发布状态和测试结果描述当时修订。当前 1.4.2 的发布范围与验证请见根目录 CHANGELOG-1.4.2.md、VERIFICATION.md。

参考 `Kirota233/XM-Editing-Studio` 的本地批处理水印实现，保留原有
WebAV 页面和 Edge/Chrome 独立窗口入口。水印页现在可切换“本地批量”
与“浏览器处理”；本地模式支持默认样片图、自定义图片/文字、布局、
分辨率、队列进度、取消、失败重试及输出定位。

本地模式采用 Windows Media Foundation，优先使用系统硬件转换。
运行时引擎从受 SHA-256 校验的归档复制到用户配置目录；不会清理
其他缓存目录。输出文件若存在，则增加 `(1)` 等序号，避免覆盖成片。
原生引擎不需要 Chrome/Edge，也不改动原视频。

验证：259 项 JavaScript 回归检查、16 项草稿扫描检查和 46 项剪映
引擎检查通过；原生引擎在 Windows 11 上完成带音频短视频的两次
合成，第二次未覆盖第一次输出。更新后的本机 EXE 与 ASAR 头部哈希
匹配，在隔离配置下加载主窗口并提供水印资源。
